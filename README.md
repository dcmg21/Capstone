# Capstone Working Folder - Start Here

Our shared team workspace. One simple rule:

- **Code goes to GitHub.**
- **Everything else lives here in OneDrive**, shared with the team.

## Layout

| Folder | What's in it | Push / share |
|--------|--------------|--------------|
| `Code/brand_scoring/` | The capstone code (this folder is the git repo) | **Push to GitHub** |
| `Team/` | Our working files: status log, dashboard, team plan, `Pitch/`, `Meetings/` | **OneDrive** (shared folder) |
| `Course/` | Class reference: `Syllabus/`, `Templates/` | reference only |
| `Paper/` | Paper drafts go here (Draft 0, 1, 2, 3, final) | OneDrive + submit via 2DS |
| `Archive/` | Parked prior idea (`wastewater`), not part of this capstone | ignore |

## Two shares to set up (do once)

1. **OneDrive:** right-click this `Capstone` folder -> Share -> add Devin (SMU email), **Can edit**. That is our shared workspace, so no more sending files in Teams.
2. **GitHub:** create/host the `Code/` repo and add Devin as a collaborator. That is where the code lives.

## Rule of thumb

If it is `.R` / a script -> it belongs in `Code/` and goes to GitHub.
If it is a doc, slide, dashboard, or note -> it belongs in `Team/` (or `Paper/`) and is shared through OneDrive.
